# GEEvo: Game Economy Generation and Balancing with Evolutionary Algorithms
* Time is a universal resource
* Small adjustments can have huge impacts on the economy
* Probabilistic elements increase this effect
* Testing is manual and time intensive
* Simulate economies represented by graphs
* Aimed at Procedural Content Generation
* Generators - Generate random valid economies
* Balancers - Adjust edge weights to optimize for different objectives
* Game designers use players' impatience to monetize in free-to-play games
* Game rule constraints and balancing constraints can be solved separately through different EAs
* Ability cooldowns/critical rates are modeled using pools/gates
